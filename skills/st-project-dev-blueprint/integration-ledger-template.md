# integration-ledger-template — 集成接口台账模板

> 配套 [st-project-dev-blueprint](SKILL.md) 流程 ③ 使用。台账是蓝图 §4 的正文,可
> 单独成册也可内嵌;编号 `IF-NN` 全项目顺号。示例均为通用业务,与任何具体项目无关。
>
> 核心纪律一句话:**每个接口逐条有双方责任人;「待定」必须带期限;零外部集成也要
> 明写——空白与零是两回事。**

## 使用规则(先读)

1. 素材来源三处逐一扫:签字 SRS 全文(**含范围外章节**——明确不含的接口进「显式
   排除」区,防将来「默认包含」扯皮)、pre-quote 假设与除外清单的接口对接假设
   (逐条核对都有对应行或对应排除)、修正链/获批变更里新增的集成要求;
2. 九要素(编号/对接系统/方向/协议/数据项概要/接口文档责任方/联调环境责任方/
   对方配合人/验收方式)逐列填齐;查不到的填「待定 + 向谁要 + 期限」,**无期限的
   待定 = 没登记**;期限到了未落实 → 报 PM,不自行顺延;
3. 责任方只有三种合法值:我方 / 客户方 / 第三方(写明哪家)——「双方协商」不是
   责任方,是没定;
4. 验收方式写到可判定粒度(联调环境里双向各跑通一条真实数据 / 对账文件核对一致),
   禁「联调通过」这类不可判定表述——纪律同 req-baseline 验收标准;
5. 台账更新随蓝图更新纪律(SKILL.md ⑦):只由修正/获批变更触发,更新记录只增不改。

## 台账总表(九要素,一接口一行)

| 编号 | 对接系统 | 方向 | 协议 | 数据项概要 | 接口文档责任方 | 联调环境责任方 | 对方配合人 | 验收方式 |
|---|---|---|---|---|---|---|---|---|
| IF-01 | (示例)客户财务系统 | 出 | HTTP API | 应付单据日汇总推送 | 第三方(财务软件商) | 客户方 | 待定(向客户 IT 部要,期限 <日期>) | 联调环境推送一日真实数据,财务侧金额核对一致 |
| IF-02 | (示例)集团主数据平台 | 进 | 文件/SFTP | 物料档案增量同步 | 客户方 | 客户方 | <姓名/岗位> | 同步一批增量后,两侧按物料编码抽核 N 条一致 |

**个数统计行(硬,总表末尾必有)**:

> 接口合计:**k 个**(进 a / 出 b / 双向 d);责任方分布:文档我方 x / 客户方 y /
> 第三方 z;含「待定」要素的接口 t 个(全部带期限,逐个见明细)。

**显式排除区**(SRS 范围外章节明确不含的集成,逐条列防扯皮;没有则写「无」):

| 排除项 | SRS 出处 | 说明 |
|---|---|---|
| (示例)与旧 OA 系统单点登录 | 范围外 §x | 本期不实现,如需走变更 |

## 零外部集成的写法(硬)

全项目确实无外部集成时,台账正文只写一句结论 + 依据,禁留空白页:

> **本项目零外部集成**——已扫描签字 SRS 全文(含范围外章节)与 pre-quote 接口
> 对接假设,无任何与外部系统的数据交换要求。(核对日期:<日期>;基于 SRS V<x> +
> 修正 1..N)

## 接口条目明细(逐接口复制;简单接口可只留总表行)

```markdown
### IF-NN:<对接系统> · <方向> · <一句话用途>

- SRS 出处:§<章节>(修正链有涉及的注明修正号)
- 数据项:<逐项列名与口径要点;口径拿不准的进 req-baseline 疑点/差异通道,不猜>
- 频率与时效:(示例)每日一次 / 准实时,延迟容忍 <N> 分钟
- 触发与重试:谁发起;失败后重试与人工介入责任在谁
- 联调前置:接口文档到位期限 / 联调环境到位期限 / 测试账号与样例数据由谁给
- 对应报价工作项:<编号>(对不上 = 进蓝图 §6 差异清单,禁默默吸收)
- 对应假设条目:pre-quote 假设清单第 <n> 条(无对应假设的接口 = 报价时没设防,
  单独报 PM)
- 风险备注:<对方系统无文档 / 对方排期未定 等;写「若成真的后果」>
```

## 自检清单(台账定稿前逐条过)

- [ ] 九要素逐列无空白:填实值或「待定 + 向谁要 + 期限」;
- [ ] 个数统计行存在,数字与总表行数对得上;
- [ ] 每个「待定」都有期限;责任方无「双方协商」类糊话;
- [ ] 验收方式逐条可判定,搜不到「联调通过」「对接成功」类表述;
- [ ] pre-quote 接口对接假设逐条有着落(对应行 / 显式排除),零遗留;
- [ ] SRS 范围外章节的集成排除项已列入显式排除区;
- [ ] 零集成时有结论句 + 核对依据,而不是空表。
