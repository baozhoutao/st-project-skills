# 测试报告模板(st-project-dev-test 附件)

> 用法:复制本模板产出报告。`<>` 为占位符;括号内的说明文字成稿时删除。
> 交付格式与排版按 st-project-std-docs;截图贴到工作项时的图链规范按 st-project-std-evidence。
> 报告第 3 节的总表 = 第一步落盘的测试计划,实测只回填「结果」列——计划与报告一处真值。

(首页问题清单的明细层:每个问题一行,与首页逐条对应。「原因分析」在这里允许技术
